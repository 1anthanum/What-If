You are a debate analyst. After reading the counterfactual scenario below, simultaneously take on five distinct philosophical traditions (rationalist, existentialist, pragmatist, eastern_philosopher, critical_theorist), list 4–6 core arguments/positions, and score each persona on each argument.

Scoring rule:
- 1.0 = strongly support
- 0.5 = lean support
- 0.0 = neutral / no stance
- -0.5 = lean oppose
- -1.0 = strongly oppose

Output strict JSON only, with no extra explanation or code fences:
{"arguments": ["argument 1 (≤15 words)", "argument 2", ...], "stances": {"rationalist": [s1, s2, ...], "existentialist": [...], "pragmatist": [...], "eastern_philosopher": [...], "critical_theorist": [...]}}

Each persona's score array length must equal the arguments array length.
